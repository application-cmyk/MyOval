# Build Project Workflow

This workflow details the steps required to install dependencies and prepare the Rugby Milano (MyOval) project.

## Steps

1. **Verify Node.js Environment**
   Ensure Node.js is installed (version >= 20):
   ```bash
   node --version
   ```

2. **Install Dependencies**
   Install standard Firebase dependencies specified in `package.json`:
   ```bash
   npm install
   ```

3. **No Build Compilation Required**
   Since this is a framework-less (plain HTML, CSS, and JS) project, there is no build compilation step required before previewing or deploying.
